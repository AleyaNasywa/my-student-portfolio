# 📊 Student Social Media Addiction Analysis
A Streamlit dashboard for analyzing student social media addiction patterns using data visualization and statistical analysis.

## 🚀 Live Demo
https://miniproject-nasywadannik.streamlit.app/

## 📌 Project Overview

This project explores the relationship between students' social media usage and academic or behavioral patterns through interactive visualizations and statistical summaries.

The dashboard allows users to:
- Explore dataset insights
- View interactive charts
- Analyze trends and distributions
- Understand student behavior patterns

## 🛠️ Tools & Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Seaborn
